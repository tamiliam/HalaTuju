Where each kind of words shows
ChipField name only. Drawer, opened document and student screen.
Short reason DrawerOne line per amber/red chip. Same colour as the chip. Fixed words (English, Malay, Tamil).
Both values side by side OpenedWhat the document says vs what the application says.
Names, IC numbers, addresses OpenedOnly in the opened document. Never in the drawer.
Full AI notes OpenedEach sentence on its own line. The drawer shows only a small grey speech-bubble with the count.
Read time DrawerShort: "read 25 Nov, 09:12". The year shows only when it is not this year: "read 25 Nov 2026, 09:12". Opened document: always the full date, plus the upload time.
